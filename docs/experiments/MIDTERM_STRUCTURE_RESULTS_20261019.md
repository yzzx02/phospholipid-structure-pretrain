## 决策依据和限制

- Morgan 的 512 条诊断合法 Polar 从 29.49% 提升至 43.95%，Top-5 命中 4 条；原始完整结构 exact 仍为 0。
- Morgan 可选分子式筛选覆盖 14/512，完整命中 2/512；不能将筛选内准确率代替整体准确率。
- 2,000 条 validation 的链槽完全正确率仅由 3.60% 到 3.75%，不能仅用 loss 或 token accuracy 判定结构生成成功。
- 所有已完成训练与评价阶段未新增 Windows GPU 转储；最终编码器比较和全量训练建议待 GINE 中程分析完成。

- 512 条为分层诊断样本，包含约三分之一单链样本，不能将其比例外推到整个库。
- 冻结 validation 无 P/A 样本；不移动 split 来制造覆盖。
- 20,000 条训练池不等于完整 201.5 万条预训练；尚无 MS/MS 输入或微调验证。
- Math attention 下本轮未新增 GPU 转储，仅支持这些已执行负载的稳定性；不证明驱动问题彻底解决或硬件必然正常。
- 首次 FP1001 生成已完成，但报告收尾发生 Path 类型错误；修正后以哈希绑定复用全部 640 条原始输出，只重算 teacher forcing。
