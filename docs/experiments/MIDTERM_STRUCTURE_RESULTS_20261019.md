## 决策依据和限制

- 固定 512 条诊断集上，Morgan 合法 Polar 从 29.49% 升至 43.95%，GINE 从 22.46% 升至 48.44%；5,000 步 EOS 均为 99.61%。改善主要体现在生成合法性，不能等同目标头基准确率。
- 所有比较节点的原始 greedy Polar graph exact 和完整结构 exact 均为 0。Morgan 5,000 步 Polar Top-5 为 4/512，GINE 5,000 步为 0/512，GINE 的最佳观察值为 4,000 步的 2/512；小样本稀疏命中不足以证明编码器普遍优劣。
- Morgan 5,000 步原始分子式匹配 3/512；可选 Top-5 公式筛选覆盖 14/512、完整命中 2/512（总体 0.39%，筛选内 14.29%）。GINE 5,000 步原始分子式匹配 4/512，筛选覆盖 11/512、完整命中 0；GINE 在 3,000/4,000 步各有 1 条筛选后完整命中。
- 2,000 条原 validation 的链槽完全正确率在 5,000 步仅 Morgan 3.75%、GINE 3.80%。512 条分层集的 chain-set 45.90%/47.66% 不能外推至整个库；该诊断集刻意覆盖罕见类别且约三分之一为单链。
- Morgan 参数 16,766,021，GINE 参数 15,738,824。本机相同有效 batch=16 下 Morgan 续训吞吐约 14 steps/s，GINE 约 5.9–7.5 steps/s；GINE 的合法率优势未转化为稳定的 Top-5/完整目标命中优势。后续以 Morgan 作为成本基线，保留 GINE 对照，不凭单一 loss 或 token accuracy 选型。
- 两模型均从原 1,001 步 checkpoint 真正恢复；训练池、优化器、LR、seed、公式统计、Math SDPA 和 FP32 保持不变。独立保留并审计每模型 1,500/2,000/2,500/3,000/3,500/4,000/4,500/5,000 步，共 16 个检查点。
- 本轮全部训练和评价未新增 Windows GPU 转储，未触发停滞保护；不能据此证明默认 attention 故障已根治或硬件必然健康。未改变驱动、核心软件、精度或 TDR 设置。
- 实际 20,000 条训练池的模板配对为 H 11.01%、C 29.27%、HC 59.73%，目标可同时具有多种模板类型；保持原 normal/polar-excluded 50/50 配置。仅统计，不进行配比消融。
- Test split 未用于训练、评价或选择；这些结果仍是 structure-oracle 检索下的模板+可信分子式实验，尚无 MS/MS 条件输入或微调验证。少量命中指训练未见、库中已有的验证结构，不证明发现新化合物。

- 512 条为分层诊断样本，包含约三分之一单链样本，不能将其比例外推到整个库。
- 冻结 validation 无 P/A 样本；不移动 split 来制造覆盖。
- 20,000 条训练池不等于完整 201.5 万条预训练；尚无 MS/MS 输入或微调验证。
- Math attention 下本轮未新增 GPU 转储，仅支持这些已执行负载的稳定性；不证明驱动问题彻底解决或硬件必然正常。
- 首次 FP1001 生成已完成，但报告收尾发生 Path 类型错误；修正后以哈希绑定复用全部 640 条原始输出，只重算 teacher forcing。
