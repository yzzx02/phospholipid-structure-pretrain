# v0.4-FP 50k 稳定版：实测结果

完成状态：completed_50k_5000_all_generation_gates；累计 5,000 optimizer steps，80,000 次目标输入。
本轮从随机权重训练，与旧 20k/3,000-step 模型独立；没有开展全库预训练或 MS/MS 微调。
固定 FP 架构 16,468,671 参数，Math/FP32、TF32关闭、有效batch16；内部连接标记与 Builder 保持原样。

## 数据和工程门槛

50,000 个真实 TRAIN 行对应 50,000 个不同 Polar graph、31,206 种式；旧 20k 池为 18,112 个不同 graph、11,233 种式。
单链5,374、双链44,626；A/A31,067、O/A13,558、稀有P/A1。phosphate21,305、phosphonate19,367、polyphosphate9,328。
选择覆盖 family、长度和元素类别，并优先覆盖式；因此同时改变了 graph 覆盖及抽样分布，不能将差异只归因于池大小。
CORE 14,253、EXTENDED 35,747；包括冻结库已有的12,585个phosphate analog和1个keto-inositol。本轮没有新增或伪造结构；这些库内生成衍生物不代表已经获得真实MS/MS验证。
K3、阈值0.2，实际149,967个模板配对，H占80.1996%，5个目标合法fallback，零无模板目标。
复用相同检索契约下的冻结全TRAIN公式统计；所有实际模板对重新检查 TRAIN-only、异头基、链型和相似度。

正式运行前CPU测试 366 项通过；最终回归 368 项通过。真实CPU连续4步与2+2恢复权重、优化器、随机状态、消费位置和loss序列完全一致。
CUDA实际20+5步探针通过，再从随机权重开始正式实验。子模块审计单独核对 FP、公式MLP、融合、TCLS、Set Encoder、Decoder 的更新和非零优化器梯度矩。

## 与旧20k/3,000比较

- 50k_step3000_elements_grammar_beam20_n512：覆盖差 -4.49 个百分点；Top5差 +0.78、Top10差 +0.59 个百分点；全目标Top1 Polar Tanimoto差 -0.0094。
- 50k_step5000_elements_grammar_beam20_n512：覆盖差 +7.03 个百分点；Top5差 +4.30、Top10差 +3.71 个百分点；全目标Top1 Polar Tanimoto差 +0.0372。
- 50k_step5000_elements_grammar_beam50_n512：覆盖差 +3.71 个百分点；Top5差 +3.91、Top10差 +4.88 个百分点；全目标Top1 Polar Tanimoto差 +0.0394。

512条为反复使用的诊断集。JSON的配对bootstrap区间仅描述这些诊断目标的重采样差异，不代表独立泛化置信度。20k/3,000对50k/5,000还改变了步数，只能描述性比较。

## GPU监控和结论

完成12个独立受监控CUDA作业；观察到显示重置事件0，可读目录新增/变更GPU dump 0。全部作业前后保护的checkpoint哈希一致，无自动重试。
普通进程无法读取受保护WATCHDOG目录，不能把未观察到事件解释为绝无转储；System4101、WER141/117、其他可读目录及NVIDIA遥测仍持续监控。

1. 本机RTX4070 SUPER的原生Windows训练/恢复和约束推断路径已实测通过。保留50k/5,000-step FP作为后续研究的稳定工程基线；本次观测范围内无新GPU事件，不能据此保证长期绝无黑屏。
2. 联合50k/5,000设置比旧20k/3,000的Beam50覆盖提高3.71个百分点，Top5由18增至38/512，Top10由22增至47/512，全目标Top1 Polar Tanimoto由0.2342升到0.2736。结果显示本轮联合设置有效，但训练池与步数同时改变。
3. 同步数3,000比较并未给出一致改善；配对诊断区间跨0。不能独立证明增加头基覆盖是改善原因。若要分离池大小与步数，下一轮先补20k/5,000控制；本轮没有自动执行该控制。
4. 生成仍有明显局限：Beam50合格候选98.78%为错误Polar图；仅49个目标真实图进入Beam，其中2个排在10名后，463/512根本未进入。模板完全复制9/4030，主要失败不是简单复制模板。图差异常涉及P邻域、末端/官能团、分支和环，但特征可重叠，不能强行赋予唯一化学原因。
5. 改善集中在短头基：最终Beam20的36个Top5命中有29个来自16–31 token档；长头基仍困难。建议暂不扩大到全201.5万库或继续无界追加训练，也不增加网络层/分支。优先考虑结构模板编辑及真实MS/MS条件的小规模验证。
6. 权重可作为后续MS/MS条件微调的初始化，但当前只有structure-oracle、可信公式和外部给定链的诊断，尚未经过真实谱图和独立目标验证，不具备MS/MS鉴定准确率结论。下阶段训练需另行设计和授权。

生成正确式、生成正确Polar、真实MS/MS证据支持是三种不同结果。TEST未用于本轮训练或选模。
