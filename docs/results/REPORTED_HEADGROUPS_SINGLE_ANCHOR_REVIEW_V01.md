# 单连接 Polar 头基看图审核，2026-10-21

在 v0.1 的 182 个结构图上进行独立初筛，原库及全部原始来源保持不变。
本轮只绘图、筛选及提供人工审核界面，没有训练模型或改动 Builder。

|初筛集合|不同图数|
|---|---:|
|保留|44|
|明确排除|129|
|待人工判断|9|
|默认看图集合，保留加待判断|53|

44 个初筛保留项均已通过 v0.1 的原有 Builder 检查。
53 个默认展示项中有 49 个 Builder 通过；其余 4 个仍处于待判断集合。
“保留”是本轮额外脂质锚点筛选结果，不代表新增文献验证、Decoder 支持或人工批准。

按实际 Polar 图识别额外长链，避免因完整脂质原名含脂肪酸而误删 PC/PE 等小头基。
CL/BMP/LBPA/SLBPA/DEACL/BPG 和 NAPE/NAPS 型额外连接按用户要求排除。
连续至少 8 个仅有 C/H 邻接的非环脂肪碳、甾醇四稠环锚点也触发排除，
因此 Builder 通过的额外古菌醚链、甾醇糖脂锚点不会混入保留集合。

待判断集合包含 3 个氧化脂质来源 PE 加合物、3 个氨基酰 PG 位置图、
1 个短乙酰糖头基、1 个 Builder 不支持的含 As 头基、1 个来源名称冲突项。
短酰基或氨基酸酯不冒称为明显脂肪酸长链，由用户看图确定是否保留。
羧酸、多 P 或多个糖环本身均不触发排除。没有删链或篡改分子图来使结构通过。

全部 182 个图都有 RDKit SVG 和 PNG，默认 53 个图另有 9 页图册，
129 个排除项另有 22 页复核图册。蓝色突出正确的 P-[*:1] 连接位点，
红色提示检出的长链或甾醇原子。原始立体结构保留在 v0.1 来源库。

离线 HTML 可搜索、放大、逐图标记保留/排除/待判断并导出 CSV/JSON。
同名结构不合并；使用稳定 Polar ID 保存决定。
浏览器本地缓存与 JSON 备份分开，路径或浏览器变化时可导入备份。
Excel 共两页，包含 182 张嵌入结构图及独立人工决定/备注栏。
Excel 和 HTML 的人工决定不自动同步，均不自动写回正式模板库。

相关筛选与 v0.1 回归测试共 29 项通过。保存后工作簿的图数、初筛统计和
全部未预填的人工决定栏经过独立 XML 检查；SVG 检查覆盖每个源图的全部原子编号。
完整 HTML、结构图、图册、Excel、CSV、审核备份和详细校验留在 G 盘，
GitHub 只发布代码与不含逐图结构的汇总。

复现入口：`scripts/build_headgroup_structure_review_v01.py`、
`scripts/export_headgroup_structure_review_v01.mjs` 和
`scripts/audit_headgroup_structure_review_v01.py`。
